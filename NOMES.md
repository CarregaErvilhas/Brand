# Os nomes

De onde vem o nome de cada site e da sua mascote, e como se escreve.

| Nome | De onde vem | Como se escreve |
| --- | --- | --- |
| **O Carro Elétrico** | O assunto do grupo. É o site principal, e o domínio dele é o de todos os outros (`*.ocarroeletrico.com`) | Com maiúsculas. Na contração: "d'O Carro Elétrico" |
| **ohmigo** | "ohm" + "amigo": o teu amigo dos carregamentos | Sempre em minúsculas, mesmo no início da frase |
| **Ohmi**, a mascote do ohmigo | (por preencher) | Com maiúscula |
| **Voltaria** | (por preencher) | Com maiúscula |
| **Comparador CEME** | O que faz: compara os tarifários dos CEME, os comercializadores de eletricidade para a mobilidade elétrica | "Comparador CEME"; em inglês, "CEME comparator" |
| **Postos PT** | O que mostra: os postos de carregamento públicos de Portugal. O endereço é `nap`, do Ponto de Acesso Nacional (NAP) de onde vêm os dados | "Postos PT" |
| **olh'o'posto** | Lê-se "Olha o posto": as fotos mostram como é o posto antes de lá chegares | Em minúsculas e com os dois apóstrofos. Os leitores de ecrã leem "Olha o posto" (`aria-label`, `<title>` dos SVG). Onde as maiúsculas se veem, o identificador é `OlhaOPosto`; em minúsculas seguidas, "olhaoposto" lê-se "Olhão", por isso só se usa onde as minúsculas são obrigatórias (domínio, nomes técnicos) |
| **Pic**, a mascote do olh'o'posto | De *picture*, foto em inglês | Com maiúscula |
| **AmpereArchive** | (por preencher; o endereço é `ohm-age`) | Uma palavra, com o A de Archive em maiúscula |
| **Panoramax** | O projeto de software livre de fotos de rua em que corre o servidor de fotos do olh'o'posto. O nome não é nosso | "Panoramax" |

## Um nome novo

- Diz o que o site faz ou brinca com uma unidade elétrica (ohm, volt, ampere). Fica no mesmo registo dos outros.
- Lê-se bem em português. Confirma como se lê em minúsculas seguidas, porque é assim que aparece no domínio.
- Fica em `<nome>.ocarroeletrico.com`.
- A mascote pode ter nome próprio, curto e com maiúscula (Ohmi, Pic).
