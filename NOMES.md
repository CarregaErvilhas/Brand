# Os nomes

De onde vem o nome de cada site e da sua mascote, e como se escreve.

Os nomes próprios do grupo são todos trocadilhos com a energia: uma unidade elétrica (volt, ohm, ampere) colada a uma palavra do dia a dia, muitas vezes pelo som, como se diz em voz alta. Os sites que não têm trocadilho (O Carro Elétrico, Comparador CEME, Postos PT) têm o nome do que fazem.

| Nome | De onde vem | Como se escreve |
| --- | --- | --- |
| **O Carro Elétrico** | O assunto do grupo. É o site principal, e o domínio dele é o de todos os outros (`*.ocarroeletrico.com`) | Com maiúsculas. Na contração: "d'O Carro Elétrico" |
| **ohmigo** | "ohm" + "amigo", lido "oh migo": o teu amigo dos carregamentos | Sempre em minúsculas, mesmo no início da frase |
| **Ohmi**, a mascote do ohmigo | "ohm" + "oh mi", à inglesa (*oh my*) | Com maiúscula |
| **Voltaria** | "volt" + "voltar a ler": o livro a que se volta para ler as regras | Com maiúscula |
| **Comparador CEME** | O que faz: compara os tarifários dos CEME, os comercializadores de eletricidade para a mobilidade elétrica | "Comparador CEME"; em inglês, "EV Tariff Comparison" |
| **Postos PT** | O que mostra: os postos de carregamento públicos de Portugal. O endereço é `nap`, do Ponto de Acesso Nacional (NAP) de onde vêm os dados | "Postos PT" |
| **olh'o'posto** | "Olha o posto", escrito como se diz, a mesma adaptação fonética do "oh migo" no ohmigo: as fotos mostram como é o posto antes de lá chegares | Em minúsculas e com os dois apóstrofos. Os leitores de ecrã leem "Olha o posto" (`aria-label`, `<title>` dos SVG). Onde as maiúsculas se veem, o identificador é `OlhaOPosto`; em minúsculas seguidas, "olhaoposto" lê-se "Olhão", por isso só se usa onde as minúsculas são obrigatórias (domínio, nomes técnicos) |
| **Pic**, a mascote do olh'o'posto | De *picture*, foto em inglês | Com maiúscula |
| **AmpereArchive** | "ampere" + "arquivo": o arquivo da rede. O endereço, `ohm-age`, junta "ohm" (a resistência) a *hommage*, homenagem em francês | Uma palavra, com o A de Archive em maiúscula |
| **Panoramax** | O projeto de software livre de fotos de rua em que corre o servidor de fotos do olh'o'posto. O nome não é nosso | "Panoramax" |

## Um nome novo

- Um nome próprio é um trocadilho com a energia: uma unidade ou um termo elétrico colado a uma palavra do dia a dia, de preferência pelo som. Se não houver trocadilho, o nome diz o que o site faz.
- Lê-se bem em português. Confirma como se lê em minúsculas seguidas, porque é assim que aparece no domínio.
- Fica em `<nome>.ocarroeletrico.com`.
- A mascote pode ter nome próprio, curto e com maiúscula (Ohmi, Pic).
